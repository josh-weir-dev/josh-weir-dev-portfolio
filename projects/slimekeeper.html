Slimekeeper

A top-down roguelike focused on dynamic gameplay systems, combat loops, and procedural enemy behavior.

C# Unity Procedural Generation
View Source on GitHub

Systems Breakdown

  • Procedural Dungeon Generation

    • Apporach:

    Grid-based algorithm utilising randomised array starting points and template rooms.

    Path Validation:

    Implemented path-checking logic to guarantee a valid traversal route from the starting point to the final room

    Key Challenge:

    Prevented room overlapping and solved layout dead-ends that blocked player progression.

  • Enemy Spawning

    • Approach:

    Dynamic multi-point spawner designed to ensure a balanced and challenging enemy presence.

    Pacing & Caps

    Applied a global enemy population cap alongside spawn delays to preserve game balance.

    Key Challenge:

    Positioned spawn points strategically to avoid exploit zones and force direct engagement with pathfinding AI.
